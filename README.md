# quant-notebooks

A public research log in quantitative finance. Python notebooks documenting hands-on work through options pricing, volatility modelling, Greeks, Monte Carlo simulation, and statistical edge — implemented from primary sources, not tutorials.

Each notebook is designed to be read as much as run: it sets up the mathematical problem, derives or implements the model in Python, and tests the result against theory or empirical data.


## Notebooks

| # | Notebook | Topic | Status |
|---|----------|-------|--------|
| 01 | `01_black_scholes_pricing.ipynb` | Black-Scholes analytical pricing of European options | Planned |
| 02 | `02_bs_greeks.ipynb` | Greeks from Black-Scholes (delta, gamma, vega, theta, rho) | Planned |
| 03 | `03_monte_carlo_european.ipynb` | Monte Carlo pricing of European options | Planned |
| 04 | `04_mc_convergence.ipynb` | Convergence of MC estimates to the Black-Scholes price | Planned |
| 05 | `05_mc_path_dependent.ipynb` | Monte Carlo for path-dependent options (Asian, barrier) | Planned |

Additional notebooks will be added as the curriculum progresses. Status updates per notebook as they ship.
